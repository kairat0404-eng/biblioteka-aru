# Библиотека АРУ: онлайн-поиск по neb.arsu.kz

Сайт и мобильное приложение (PWA) для поиска в электронной библиотеке
АРУ им. К. Жубанова. Все данные берутся **в реальном времени** с https://neb.arsu.kz:
при каждом запросе сервер сам заходит на сайт, выполняет поиск и возвращает результаты.

## Возможности

- **«Спросить» (ИИ-помощник)** — задаёте вопрос обычными словами («найди информацию про битву
  за Ленинград»). Приложение:
  1. с помощью ИИ (Gemini или Claude) превращает вопрос в 5–10 коротких поисковых запросов (основы слов, более
     широкие темы, казахские варианты);
  2. выполняет их в каталоге neb.arsu.kz и ранжирует найденные книги;
  3. ИИ пишет структурированный ответ (кратко → разделы → «Что читать в библиотеке АРУ»),
     текст появляется по мере написания, номера [n] ведут к найденным книгам.

  Важно: текст ответа ИИ пишет из общих знаний. Из библиотеки берутся только описания книг
  (название, авторы, год), потому что сайт не даёт доступа к самим файлам. Об этом сказано
  под каждым ответом.
- **Поиск «Везде»**: одновременно по названию, авторам и ключевым словам, без дублей.
- Поиск по любому полю сайта: название, тематика, автор(ы), вид издания, язык, ключевые слова.
- Фильтры: тематика (150), вид издания (20), язык ресурса (5).
- **Каталоги**: 21 каталог → тематики → список ресурсов с подгрузкой страниц.
- Кнопка «Открыть» открывает книгу в официальном просмотрщике neb.arsu.kz.
- Записи без электронной копии тоже показываются, с пометкой «Только описание».
- Избранное, история запросов, кнопка «Поделиться».
- Интерфейс на русском и казахском (данные тоже берутся с `/ru` или `/kk`).
- Устанавливается на телефон как приложение (Android и iPhone), тёмная тема.

## Запуск на компьютере

Нужен Node.js 22.13 или новее.

1. Установите зависимости: `npm install`.
2. Скопируйте `.env.example` в `.env` и впишите ключ ИИ — один из двух:
   - **Google Gemini (бесплатно):** ключ на https://aistudio.google.com/apikey →
     `GEMINI_API_KEY=...`. Бесплатного лимита хватает на десятки вопросов в день.
   - **Claude (платно):** ключ на https://console.anthropic.com → API Keys →
     `ANTHROPIC_API_KEY=sk-ant-...`, на балансе должны быть деньги.

   Если задан ключ Gemini, используется он. Без ключей работают поиск, каталоги
   и избранное, а «Спросить» покажет подсказку.
3. Запустите `npm start` и откройте http://localhost:3000.

Один вопрос — это два запроса к ИИ (подбор поисковых слов и ответ), ответ готов
примерно за 10 секунд. Модели выбраны по замерам скорости:
подбор слов — `gemini-3.1-flash-lite`, ответ — `gemini-3.5-flash-lite` с коротким
«раздумьем». Бесплатные модели бывают перегружены, поэтому `ai.js` пробует запасные
(`3.6-flash` и др.), а отказавшую модель 5 минут пропускает. Жёстко задать одну модель
можно строкой `GEMINI_MODEL=...` в `.env`.

**Два языка.** На какой бы язык ни был вопрос, поиск идёт сразу по русским и казахским
словам, поэтому в подборку попадают книги на обоих языках. Ответ пишется на языке
вопроса, а названия книг на другом языке переводятся в скобках. Язык определяет сервер
по служебным словам («кто», «что», «туралы», «кім»…), русским окончаниям и казахским
буквам; казахские имена внутри русского вопроса («Творчество Мағжана Жұмабаева») язык
не меняют.

**Защита и кэш.**
- Не больше 6 вопросов в минуту и 100 в день с одного адреса, не больше 2 одновременно;
  остальные API — 120 запросов в минуту. При превышении приложение пишет, сколько подождать.
- API отвечает только самому приложению: запросы с чужих сайтов отклоняются.
- Результаты поиска по каталогу, тематики и подобранные ИИ поисковые слова кэшируются
  на час. Повторный вопрос отвечается за ~3 с и не нагружает сайт библиотеки.
- На хостинге за прокси (Render и т. п.) добавьте переменную `TRUST_PROXY=1`, чтобы
  лимиты считались по настоящему адресу пользователя.
С Claude используется `claude-opus-5-5` с серверным запасным вариантом (`fallbacks: "default"`).

## Ответы по тексту книг (выгрузка библиотеки)

Если библиотека АРУ предоставит официальную выгрузку книг (PDF-файлы), приложение
будет отвечать **по тексту книг**, а не из общих знаний ИИ: после каждого факта —
номер источника [n], под ответом — книга, автор, год, **номер страницы**, цитата
с выделенными словами и кнопка «Открыть · стр. N».

> Файлы книг берутся только из выгрузки, полученной от библиотеки. Приложение не
> скачивает книги с сайта neb.arsu.kz: сайт намеренно закрывает их от скачивания.

1. Положите выгрузку в папку, например `D:\books`. Подпапки допускаются.
2. Добавьте в эту папку файл `books.csv` (разделитель `;` или `,`), чтобы связать файлы
   с каталогом сайта:

   ```
   file;rid;fid;title;authors;year
   istoriya-kz.pdf;1234;1230;История Казахстана;Кан Г.В.;2019
   ```

   `rid` и `fid` — номера книги на neb.arsu.kz из ссылки «Открыть» (`/view?rid=…&fid=…`).
   Без них книга всё равно ищется, но под ответом вместо ссылки будет имя файла.
3. Прочитайте книги:

   ```bash
   node index-books.js D:\books
   ```

   Отсканированные книги (страницы-картинки без текста) нужно распознать — добавьте `--ocr`:

   ```bash
   node index-books.js D:\books --ocr
   ```

   Распознавание медленное (порядка секунды на страницу), поэтому большую выгрузку лучше
   оставить на ночь. Индексацию можно прервать и запустить снова: уже прочитанные книги
   пропускаются. Языковые данные для распознавания (русский и казахский) скачиваются
   один раз при первом запуске.
4. Перезапустите сервер. Если по вопросу найдены страницы книг — ответ строится по ним;
   если нет — как раньше, по описаниям из каталога сайта.

Книги хранятся в базе `data/books.db` (встроенный SQLite с полнотекстовым поиском FTS5;
другой путь можно задать переменной `BOOKS_DB`). В браузер уходят только цитата и номер
страницы, полный текст страниц получает только ИИ.

Ограничения:
- Кнопка «Открыть» открывает книгу в просмотрщике neb.arsu.kz; перейти сразу на нужную
  страницу он не позволяет, поэтому номер страницы показан рядом.
- Лёгкая бесплатная модель изредка добавляет к фактам из книг мелкие детали от себя.
  Для ответов строго по тексту надёжнее более сильная модель (например, Claude).

## Как это устроено

```
Телефон / браузер ──► server.js (ваш сервер) ──► neb.arsu.kz
   public/ (PWA)        /api/search                POST /ru/search (+CSRF, сессия)
                        /api/meta                  главная: справочники, каталоги
                        /api/themes                /ru/themes?cid=
                        /api/resources             /ru/resources?cid=&tid=&page=
```

Браузер не может обращаться к neb.arsu.kz напрямую (CORS, CSRF-токен, сессии),
поэтому `server.js` работает посредником: получает токен, отправляет форму поиска,
хранит сессию для постраничной навигации и превращает HTML в JSON.

| API | Параметры |
|---|---|
| `GET /api/ask` | `q` (вопрос), `lang`. Ответ — поток SSE: `status`, `plan`, `sources`, `delta`, `done`, `fail` |
| `GET /api/search` | `q`, `type` (`all` или 1–6), `theme`, `edition`, `language`, `page`, `lang` (`ru`/`kk`) |
| `GET /api/meta` | `lang` |
| `GET /api/themes` | `cid`, `lang` |
| `GET /api/resources` | `cid`, `tid` (необязательно), `page`, `lang` |

## Публикация в интернет (чтобы работало на телефоне)

Приложение на телефоне должно открываться по **HTTPS**. Проще всего:

1. Залейте эту папку в репозиторий на GitHub.
2. На https://render.com создайте **Web Service** из репозитория:
   Build command `npm install`, Start command `npm start`. Порт подхватится из `PORT`.
   В разделе Environment добавьте переменную `GEMINI_API_KEY` (или `ANTHROPIC_API_KEY`) с вашим ключом.
   (Так же подойдут Railway, Fly.io или любой VPS с Node.js.)
3. Получите адрес вида `https://ваше-имя.onrender.com`.

## Установка на телефон

- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте адрес → «Поделиться» → «На экран “Домой”».

Нужен файл APK для Google Play? Введите адрес сайта на https://www.pwabuilder.com:
сервис соберёт Android-пакет (TWA) из этого PWA без переписывания кода.

## Файлы

- `server.js`: сервер-посредник, эндпоинт `/api/ask` и раздача статики
- `ai.js`: работа с ИИ (Gemini или Claude) — подбор поисковых запросов и написание ответа
- `books.js`, `index-books.js`: чтение выгрузки книг, распознавание сканов, поиск по страницам
- `.env.example`: образец файла с ключом
- `public/index.html`, `app.js`, `style.css`: интерфейс
- `public/manifest.webmanifest`, `sw.js`, `icon*.png/svg`: всё для установки как приложения

## Ограничения

- Сам PDF открывается через просмотрщик neb.arsu.kz: сайт защищает файлы и не даёт скачать их напрямую.
- Если на neb.arsu.kz изменится вёрстка, может понадобиться поправить разбор HTML в `server.js`.
- Поиск ищет по каталогу (название, авторы, ключевые слова), а не по тексту внутри PDF.
- Каталог ищет точную подстроку, поэтому по узким темам (например, «Ленинград») книг может
  не найтись. Тогда ИИ ищет по более широким темам («Отечествен», «СССР») и честно пишет,
  если подходящих книг нет.
